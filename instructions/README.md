# How to create a Aible

## Method 1
Take the AIBLE-INSTRUCTIONS-template.md file from this folder and fill in all PLACEHOLDER places in the document.

Then use the new file as prompt to your AI

This is how Aible 1 was created.

## Method 2
Invent a persons name, and write down something about that person. Optionally you can use the name only without any further information provided. Now tell AI to fill in AIBLE-INSTRUCTIONS-template.md as if AI is that fictive person! And then instruct AI to execute the INSTRUCTIONS.md (or any other file generated by AI).

This is how Aible 2,3,4 are created.
